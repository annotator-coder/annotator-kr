description: >-
  An integrated PR operating system proposed and designed for an energy company's PR team, built around the 1Pager format. When a Project Owner (PO) maps out a PR blueprint as a 1Pager, related content is bundled into a C-Pack and projected to pre-defined stakeholders. After real-world operation in H1 2025, the system was refined with data for H2.
problem: >-
  PR activities were fragmented at the press release level. Content on the same topic was not reaching stakeholders with a consistent message, and there was no system to measure effectiveness.
approach:
  - 1Pager format design — a single-page PR blueprint capturing goals, key messages, expected outcomes, and communication tools
  - Structured integrated PR through a dual PO (Project Owner) / IO (Item Owner) system
  - Individual content items bundled into C-Packs and sent to stakeholders in a trackable form
  - Quantitative data (views, read time) measured alongside qualitative indicators (press coverage, meeting connections)
  - >-
    H2 improvements based on H1 lessons: real-name/anonymous dual-track, expanded recipient list, shifted to deadline-backward scheduling for C-Pack dispatch
outcome:
  - 'H1: 8 1Pagers produced and operated, with 30+ associated content items'
  - 'Key C-Pack: 200 views, average read time 11 min 34 sec (high engagement relative to standard distribution)'
  - Government ministry working-level meetings secured; multiple press coverage outcomes confirmed
  - Stakeholder journalist and columnist database built
