  언론 이슈 발생 시 모니터링 → 심각도 분류 → 대응 메시지 초안 생성까지 자동화한 AI 기반 위기대응 파이프라인. PR팀 내부
  운영 시스템.
problem: >-
  언론 위기는 속도가 생명이다. 이슈 탐지부터 대응 메시지 승인까지 걸리는 시간이 팀 역량의 병목이었다. 정보가 홍보팀에 전달되는데 평균 1시간 이상, 
  대응 방향을 잡고, 공통메시지를 만들고 협의하여 최종 확정하기까지는 3-4시간 이상이 기본적으로 소요됐다.
approach:
  - 이슈 발생시 파악된 정보를 바탕으로 최대한 빠르게 정보를 정제 
  - 과거사례와 비교 후 대응안과 메시지 초안을 작성해 의사결정을 돕는 형태 
  - 'GPT 기반 심각도 분류기 구현 (1~5단계, 이슈 유형 자동 태깅)'
  - 기존 대응 사례 DB 기반 RAG 파이프라인으로 초안 생성
  - 'PM2 기반 서버 운영, 생성된 패키지는 아카이브로 재학습'
outcome:
  - '이슈 탐지→초안 생성 시간: 2시간 → 15분 이하'
  - 과거 대응 형태 파악, 프로세스에 맞는 절차 확인
  - 팀 내 위기대응 프로세스 표준화 (SOP 자동 연동)
