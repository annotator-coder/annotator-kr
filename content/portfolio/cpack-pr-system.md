description: >-
  에너지기업 PR팀에 제안·설계한 1Pager 기반 통합 PR 운영 시스템. PO(프로젝트 오너)가 1Pager로 PR 청사진을 그리면, 연관
  콘텐츠를 C-Pack으로 묶어 사전 정의된 Stakeholder에게 투사하는 파이프라인. 2025년 상반기 실전 운영 후 데이터 기반으로
  하반기 시스템을 정교화해 활용도를 높였다.
problem: >-
  PR 활동이 보도자료 단위로 분절되어 있었다. 같은 주제의 콘텐츠가 Stakeholder에게 일관된 메시지로 도달하지 못했고, 효과를 측정할
  체계가 없었다.
approach:
  - 1Pager 포맷 설계 — 목표·핵심 메시지·기대효과·커뮤니케이션 도구를 한 장에 담는 PR 청사진
  - PO(프로젝트 오너)/IO(아이템 오너) 이중 체계로 통합 PR 구조화
  - 개별 콘텐츠를 C-Pack으로 묶어 추적 가능한 형태로 Stakeholder 발송
  - 조회수·열람 시간 정량 데이터 + 기사화·미팅 연결 정성 지표 병행 측정
  - >-
    상반기 Lesson&Learned 기반 하반기 개선 — 실명/익명 투트랙, 수신자 확대, C-Pack 발송 목표 일정 역산
    방식으로 전환
outcome:
  - '상반기 1Pager 8건, 연관 콘텐츠 아이템 30여 개 제작·운영'
  - '주요 C-Pack 조회 200회, 평균 열람 시간 11분 34초 (단순 배포 대비 높은 몰입도)'
  - '정부 부처 실무 미팅 연결, 언론 기사화 다수 등 실질 효과 확인'
  - Stakeholder 기자·칼럼리스트 DB 구축
