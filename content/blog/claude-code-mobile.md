홍보팀은 외근이 많다. 외부 미팅이나 행사로 이동할 때면 스마트폰으로 업무를 보긴 하는데, 영 성에 차지 않는다. 

노트북을 가지고 다니면서 일하기는 어렵고, 생각보다 잃어버리는 시간이 많다. 

지금은 다르다. 지하철 안에서도, 외부 미팅 마치고 카페에서도 스마트폰으로 Claude Code를 실행한다.

**왜 이런 게 필요했냐면**

Claude Code를 꽤 적극적으로 쓰는 편이다. 자동화 스크립트를 짜고, 업무 흐름에 AI를 끼워 넣는 실험을 계속하고 있다. 그런데 외부 미팅이 잦다 보니, 미팅 사이 짬에 뭔가 돌려보고 싶어도 노트북을 꺼내기 애매한 상황이 많았다.

그러다 떠오른 발상이 있었다. 굳이 스마트폰에서 실행할 필요가 없다. 사무실에, 집에 있는 맥북에 SSH로 붙으면 된다.

**핵심은 두 도구다**

Tailscale은 VPN인데, 일반적인 VPN과 달리 기기 간 Mesh 구조로 연결된다. 공유기 포트포워딩 같은 복잡한 설정이 필요 없다. 맥북과 스마트폰을 같은 Tailscale 계정으로 로그인하면 끝이다. 외부 LTE 환경에서도 같은 와이파이 안에 있는 것처럼 맥북에 접근할 수 있다. 맥북 Tailscale IP(100.64.x.x)는 고정이라 한번 설정하면 바꿀 필요도 없다.

Termius는 iOS/Android 모두 지원하는 SSH 클라이언트다. 연결 프로파일을 저장해두면 버튼 하나로 접속된다. 호스트에 Tailscale IP를 넣고, 맥북 사용자명과 비밀번호를 입력해 두기만 하면 끝. 맥북에서 Remote Login만 켜져 있으면 된다.

**실제 흐름**

외부 미팅 끝나고 카페에 잠깐 앉는 상황을 예로 들면, 스마트폰에서 Tailscale 켜고, Termius 열어서 저장해 둔 프로파일을 탭 하면 맥북 터미널에 SSH 연결이 된다. 거기서 `claude` 명령어를 실행하면 그게 전부다.

맥북 화면이 눈앞에 없어도, 맥북의 모든 환경(파일, 코드, 설정, API 키)이 그대로 손 안에 들어온다.

스마트폰에서 타이핑이 불편할 것 같지만, Claude Code는 채팅 형식이라 생각보다 훨씬 쓸 만하다. 짧은 지시문 몇 줄로 파일을 읽고, 수정하고, 실행까지 해준다. 긴 명령어를 일일이 칠 필요가 없다는 게 모바일 환경에서 오히려 장점이 된다. Auto mode on을 해두면 중간 중간 컨펌할 필요 없이 사무실에 들어와서 결과물을 확인하면 된다. 

요즘은 OpenAI의 Codex CLI도 함께 쓰고 있다. 같은 SSH 세션 안에서 `codex` 명령어로 바로 실행된다. Claude Code와 Codex는 스타일이 조금 달라서, 작업 성격에 따라 골라 쓰는 편이다. 두 도구를 같은 환경에서 비교해가며 쓸 수 있다는 것도 이 세팅의 장점이다. (물론 codex는 앱 내에서도 이제는 실행이 된다.)

**생각보다 활용 범위가 넓다**

처음엔 급할 때 한번 써볼까 싶었는데, 이제는 습관이 됐다. 이동 중 코드를 확인하면서 수정하고, 아이디어가 떠오른 순간 바로 스크립트를 통해 만들고 테스트를 해본다. 맥북 들고 나가기 애매한 짧은 외출에도 작업 연속성이 유지된다.

**보안 메모 하나**

Tailscale은 WireGuard 기반 암호화를 쓰고, 인증된 기기 간에만 통신한다. 공개 IP로 포트를 열어두는 방식보다 훨씬 안전하다. 

**결국 이 개념이다**

클라우드 IDE나 원격 데스크톱처럼 무겁지 않고, 추가 비용도 없다. 이미 집에 있는 맥북을 서버처럼 쓰는 것뿐이다. Claude Code나 Codex를 쓰고 있다면, 이 세팅 하나로 작업 공간이 맥북 앞에만 국한되지 않게 된다.
평소에 일을 더 많이 하자는 주의는 아닌데, 스마트폰으로 업무 효율성이 1.5배 이상은 올라간 것 같아서 강주. (노트북을 안 들고 다니니 어깨에도 좋다.)
